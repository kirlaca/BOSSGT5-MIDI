    MIDI connection

    The browser talks to the MIDI interface directly (Web MIDI) - allow MIDI / SysEx access when it asks. Auto-detect asks every port on all 32 device IDs and takes the one the GT-5 answers on. Picking ports by hand works for patch changes even when SysEx replies don't come back.
